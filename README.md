### What I Build

I build software that closes the gap between raw human capability and algorithmic gatekeepers. 

Most people in tech know the feeling: you ship complex systems, scale infrastructure, or untangle messy orgs, but your resume gets dumped by an automated screener in four minutes because you didn't pack it with the exact buzzword flavor of the week. I built **[CareerWin](https://careerwin.ai)** to fix that breakdown.

* **[CareerWin.ai](https://careerwin.ai)** — An authentic career intelligence platform and Chrome extension. It anchors candidate applications to a verified Master Work Record, cuts out resume fluff, and pierces enterprise ATS portals (Workday, Greenhouse, Lever, Taleo) with 380ms form automation.
  * 🛠️ **[Real-Time ATS Resume Scanner](https://careerwin.ai/tools/ats-resume-scanner)** — Audit resumes against real enterprise parser benchmarks.
  * 🚫 **[47 Banned AI Resume Words](https://careerwin.ai/no-ai-buzzwords)** — The exact vocabulary that flags applications as automated spam.
  * 📐 **[Product Manager Altitude Scorer](https://careerwin.ai/tools/pm-altitude-scorer)** — Measure whether your portfolio reflects tactical execution or executive strategy.
  * 🧩 **[CareerWin Chrome Extension](https://chromewebstore.google.com/detail/careerwin-ai-job-applicat/hndikjplphkgdhlkhhflflmfeefkgeaa)** — 1-click tailored application pack generator and DOM autofill.

* **[Exogram Protocol](https://github.com/Richard-Ewing/exogram-protocol-rfc)** — The execution authority layer for autonomous AI agents. Deterministic runtime governance that evaluates and adjudicates agent actions before they hit production infrastructure. 0.07ms enforcement. Zero LLM inference in the critical decision loop.
